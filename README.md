# Operating Systems course at IST

# Project 1

Goal: A C project implementing the PacmanIST, a two-dimensional Pacman game where the player navigates through a maze, collects points, and avoids monsters. The project focuses on operating system concepts by extending the game with file-based level and character behavior management, process-based state recovery, and parallel execution using multiple threads.

# Project 2

Goal: A C project extending the PacmanIST into a client-server game system capable of managing multiple concurrent game sessions. The project implements communication between independent client and server processes using named pipes, a client API for establishing and managing game sessions, concurrent session handling with threads, and synchronization using producer-consumer buffers, semaphores, and mutexes.
